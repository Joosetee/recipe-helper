# Recipe Helper 🍝
### A Smart Kitchen Ingredient and Shopping Assistant

## About the Project

Recipe Helper is a beginner Python project that helps users manage recipe ingredients and check what they already have in their pantry.

It identifies missing ingredients, checks available quantities, creates a shopping list, and adjusts ingredient quantities based on the number of servings selected.

## Features

- Stores recipe ingredients and quantities.
- Checks ingredient availability in the pantry.
- Identifies missing or insufficient ingredients.
- Generates a shopping list.
- Counts the ingredients checked.
- Allows users to check their recipe again.
- Offers different serving sizes.
- Calculates adjusted ingredient quantities.
- Validates the selected serving size.
